## Governing principle

Do not merely make files exist.

Production assets must be intentionally authored or deliberately sourced, provenance/license-safe, owner-approved where visual judgment is required, runtime-ready, correctly integrated, QA-passed, and consistent with the same Otaku-mori world.

Technical readiness does not substitute for presentation approval.
